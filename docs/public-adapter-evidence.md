# Public adapter evidence map

The machine-readable authority is `data/public-adapter-evidence.json`. It records
fixed parent/child commit and tree SHAs, immutable blob locators, every production-hunk
disposition, source-derived invariants, model functions, proof sections,
negative controls, and post-repair aggregate counts.

The essential changes are:

- P01 is a rejected candidate, not a complete adapter. Its one-to-four operand
  range is finite model scope; source-reachable scalar boundaries differ.
- P04 uses independent parent and child conditional renderers and covers all
  promised branches, including `make_last_case_else` and absent loop init.
- P06 compares full LLIR trees. The same-kind `+1`/`+2` control demonstrates why
  label equality is insufficient.
- P08's invariant is tied to the fixed production call-site inventory. The four
  excluded combinations are executed and reported rather than filtered as
  successes.

No source predicate written by this project is used to assert upstream
unreachability. Where the immutable source does not establish an invariant, the
record abstains or the claim is explicitly narrowed.
